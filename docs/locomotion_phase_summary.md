# 0–30s / 130–150s ロコモーション整理

0–30 秒（First Phase）と 130–150 秒（Final Phase）の象限ベース挙動を再定義する。`docs/ground_rules.md` の制約と JSON フォーマットに従い、回転・移動・停止のタイムラインと距離を明示する。

---

## 前提
- **象限定義**: プレイマットを中央 (491.5, 466.5) で分割し、左上 (Q1)、左下 (Q2)、右下 (Q3)、右上 (Q4) の 4 象限を設定。
- **初期配置**: 30 台すべてが Q2（左下）に集約された状態で開始。
- **移動順序**: 左下 → 右下 → 右上 → 左上 → 左下 → 中心。
- **回転**: 大移動の直前に 90° 回転を実行する。First Phase では各回転に 1.0 秒を割り当て、Final Phase は従来どおり 0.5 秒で完了させる。
- **速度上限**: 直進 200 mm/s（First Phase）、105 mm/s（Final Phase）。安全率を考慮し、距離に応じた速度プロファイルをこの値以下で設定。
- **停止**: First Phase の停止時間上限は 2 秒。Final Phase は停止なしで連続動作。

---

## 群長方形のジオメトリ

### パラメータ
- toio サイズ: 横 32 mm、縦 72 mm。
- 空白（調整可能）: 横方向 `gap_x`、縦方向 `gap_y`。デフォルトは筐体寸法の 1/3 を基準にし、`gap_x ≈ 10.7 mm`、`gap_y = 18 mm` とする（必要に応じて引数で変更）。
- グリッド構成: 5 行 × 4 列（20 台）。First/Final Phase ではこの編隊を基本形とし、残り 10 台は別途編成またはフェーズ外で扱う。

### グリッド寸法
- セル幅 = 32 + `gap_x`。デフォルト ≈ 42.7 mm。
- セル高さ = 72 + `gap_y`。デフォルト = 90 mm。
- 群長方形の幅 = 32 + 3 × セル幅 ≈ **224 mm**。
- 群長方形の高さ = 72 + 4 × セル高さ = **420 mm**。

### Q2（左下象限）のセンターに合わせた場合
- Q2 中心: X = 262.75 mm、Y = 682.25 mm。
- 四隅:
  - 左上: (262.75 − 112, 682.25 − 210) ≈ (150.75, 472.25)
  - 右上: (374.75, 472.25)
  - 左下: (150.75, 892.25)
  - 右下: (374.75, 892.25)
- Y=892.25 mm はフィールド下限 898 mm 内に収まる（余裕 5.75 mm）。X 方向も十分な余裕あり。

### JSON Generator への反映
- `gap_x`, `gap_y` を引数で受け取り、群長方形の幅・高さ・各ロボットの相対オフセットを動的に計算する。
- 群中心座標を象限中心やフィールド中心にスナップし、そこから各ロボット ID の絶対座標を算出する。

### 象限中心と移動距離（速度整合性チェック）

| ラベル | 中心座標 (mm) |
|--------|---------------|
| Q1 (左上) | (262.75, 250.75) |
| Q2 (左下) | (262.75, 682.25) |
| Q3 (右下) | (720.25, 682.25) |
| Q4 (右上) | (720.25, 250.75) |
| Center | (491.5, 466.5) |

- 象限間距離:
  - Q2 → Q3, Q4 → Q1: 457.5 mm（横方向のみ）
  - Q3 → Q4, Q1 → Q2: 431.5 mm（縦方向のみ）
  - Q2 ↔ Center, Center ↔ Q3: √(228.75² + 215.75²) ≈ **314.5 mm**
- 速度上限との整合:
  - First Phase（移動 3 s）最大速度 = 457.5 / 3 ≈ 152.5 mm/s < 200 mm/s。
  - Final Phase（移動 5 s）最大速度 = 457.5 / 5 = 91.5 mm/s < 105 mm/s。
  - 中心移動も 314.5 / 3 ≈ 105 mm/s、314.5 / 5 ≈ 62.9 mm/s と制限内。
- よって指定時間内でも速度上限違反は発生しない。

## First Phase (0–30 秒)

| 区間 | 時間 [s] | 動作 | 備考 |
|------|---------|------|------|
| 0.0–1.0 | 回転90° | 初動姿勢取得（全機共通） |
| 1.0–4.0 | 左下 → 右下 | 並進 3 s（急発進 → 急停止） |
| 4.0–6.0 | 停止 | 2 s |
| 6.0–7.0 | 回転90° | 右下向け |
| 7.0–10.0 | 右下 → 右上 | 並進 3 s |
| 10.0–12.0 | 停止 | 2 s |
| 12.0–13.0 | 回転90° | |
| 13.0–16.0 | 右上 → 左上 | 並進 3 s |
| 16.0–18.0 | 停止 | 2 s |
| 18.0–19.0 | 回転90° | |
| 19.0–22.0 | 左上 → 左下 | 並進 3 s |
| 22.0–24.0 | 停止 | 2 s |
| 24.0–25.0 | 回転90° | |
| 25.0–28.0 | 左下 → 中心 | 並進 3 s |
| 28.0–30.0 | 停止 | 2 s |
| 30.0–31.0 | 回転90° | 開始姿勢（180°）へ戻す |
| 31.0–32.5 | 微調整/余裕 | 螺旋フェーズへ接続準備 |

- **距離の目安**: 左下→右下 等の横移動はフィールド幅半分（約 430 mm）、縦移動も同等。速度 200 mm/s で 3 s 動けば 600 mm を移動可能なため、余裕を持って象限中心間を移動できる。
- **JSON 出力**: 各並進フレームは `use_position=true`、回転フレームは `use_rotation=true` で分離。停止時はどちらも false（または `use_position=false` で位置保持）。

## Spiral Phase (32.5–50 秒)

- **開始条件**: 32.5 s 時点で 5×4 編隊（`gap_x=10.7 mm`, `gap_y=18 mm`）がフィールド中心 (491.5, 466.5) に整列、全ロボット 180° で静止。JSON では `time=32.5` のフレームで `use_position=true` / `use_rotation=true` を送り、前フェーズからの橋渡しを行う。
- **半径拡張**:
  - 初期半径 `r0` は中心から各ロボットまでの距離（最大 ≈191 mm）。
  - 目標半径 `r_target = min(400, r0 + (400 - r_max) * (r0 / r_max))`。中心付近はほとんど動かず、外縁のみ大きく拡散。
  - 時間カーブは `f(t) = ((t - 32.5) / 17.5)^{1.1}` とし、`r(t) = r0 + (r_target - r0) * f(t)` で滑らかに外方向へ伸長。
- **角速度**:
  - 初期角速度 `ω_fast = ω_cap * (r0 / r_max)`。`ω_cap = min(160 / r(t), 45°/s)` として接線速度を 160 mm/s 以下に制限し、中心ほど角速度を抑える。
  - 45 s 以降は `ω(t) = lerp(ω_fast, 10°/s, g(t))`（`g(t) = clamp((t-45)/(50-45), 0, 1)`）で回転を減衰させ、最終的に平行移動主体へ移行。冒頭 1.5 s で線形ランプを掛け、急激な回転を抑制。
- **サンプリング**: 32.5 s〜50 s を 0.5 s 刻みでサンプルし、各フレームで `use_position=true` / `use_rotation=true` を同時指令（位置と向きを両方更新）。
- **ノイズ**:
  - 45 s 以降にランダムウォークを付与（半径 ±5 mm、角度 ±2° を上限に 0.5 s ごとに ±1.5 mm / ±0.4° を積算）。
  - 開始時刻は `t_noise = 45.0 + ((robot_id % 5) - 2) × 0.2` で ±0.4 s ずらし、群全体が同時に乱れ始めないよう制御。乱数はロボット ID シードで決定論的に生成。
- **安全性**: 32.5 s 以降の全フレームでフィールド境界内を強制し、検証スクリプトで位置速度/回転速度/ロボット間距離（閾値 20 mm）を自動チェック。

## Final Phase (130–150 秒)

| 区間 | 時間 [s] | 動作 | 備考 |
|------|---------|------|------|
| 130.0–130.5 | 回転90° | 中心から右下へ向ける |
| 130.5–135.5 | 中心 → 右下 | 並進 5 s（105 mm/s） |
| 135.5–136.0 | 回転90° | |
| 136.0–141.0 | 右下 → 右上 | 並進 5 s |
| 141.0–141.5 | 回転90° | |
| 141.5–146.5 | 右上 → 左上 | 並進 5 s |
| 146.5–147.0 | 回転90° | |
| 147.0–150.0 | 左上 → 左下 | 並進 3 s（ +2 s 余裕で 150 s 終了） |

- Final Phase は停止を入れず連続動作。必要に応じて 150 s までの残り 3 s を緩やかな減速や静止に充当する。
- Final Phase の回転は各移動前に 0.5 s で完了し、`use_position` と `use_rotation` は常に排他。

---

## 接続条件
- **0–32.5 s → 30–50 s**: 28.0 s で中心へ集約し、30.0–31.0 s に開始姿勢へ戻す。残り時間（～32.5 s）を速度・姿勢の調整と JSON フレームの連続性チェックに使用。
- **120–130 s → 130–150 s**: 整列完了時に中心へ集約することで、Final Phase のシーケンスを即座に開始可能。
- **150 s 終了**: 左下象限で停止、以降の編集や余韻演出に合わせる。
