# 実装状況の整理

## 用語の混乱について

「群ロボット」という表現が、プロジェクト内で2つの異なる概念に使われており、混乱を招いています。

### 1. 固定フォーメーション（Formation Control）
- **定義**: 群全体が1つの剛体として動く制御方式
- **実装**: 
  - `rectangle_formation_generator.py` - 矩形フォーメーション（20台が固定相対位置で回転・移動）
  - `quadrant_json_generator.py` - 象限ベースのフォーメーション移動（0-30秒、130-150秒）
- **特徴**: 
  - 各ロボットの相対位置が固定
  - 群の中心を基準に回転・移動
  - 予測可能で制御しやすい

### 2. 自律的な群れ行動（Swarm Behavior）
- **定義**: 個々のロボットが自律的に動き、相互作用によって群として協調的な動作をする制御方式
- **実装**: 
  - ~~`tools/swarm_sim_runner.py` - Boidモデル（alignment/cohesion/separation）による群シミュレーション~~ **削除済み（重なりまくりで変な動きしかしないため）**
  - ~~`reference/swarm_control_p5js/` - p5.js版のリファレンス実装~~ **削除済み**
  - ~~`reference/swarm_control_c++/` - C++版のリファレンス実装~~ **削除済み**
- **状態**: Boidモデルは実装が不十分で削除されました。50-120秒の「群の動き」は別のアプローチで実装する必要があります。

## タイムライン別の実装状況

### 0-30秒: First Phase（固定フォーメーション）
- **実装**: `quadrant_json_generator.py`
- **動作**: 5行×4列のフォーメーションが象限間を移動
- **出力**: `quadrant_output/robot_XX.json`

### 30-50秒: Spiral Phase（螺旋運動）
- **実装**: 
  - `generate_json.py` - 30-50秒の螺旋運動（設計ドキュメントに基づく）
  - `quadrant_json_generator.py` - 32.5-50秒の螺旋運動（動的角速度制御、ノイズ付与）
- **動作**: 中心から螺旋状に拡散（放射状拡散モデル）
- **出力**: 
  - `generate_json.py` → 各ロボットのJSONファイル
  - `quadrant_json_generator.py` → `quadrant_output/robot_XX.json`（First Phaseと統合）
- **詳細**: `docs/spiral_motion_status.md`を参照

### 50-120秒: Swarm Phase（自律的な群れ行動）
- **実装**: **未実装**（Boidモデルは削除されました）
- **状態**: Boidモデルによる実装は重なりまくりで変な動きしかしないため削除されました。新しいアプローチが必要です。
- **要件**: `docs/common/ground_rules.md`の40行目に「50–120 秒: 群ロボット動作。人領域のポリゴン集合を事前に定義し、経路生成では必ず禁止領域を差し引く。」とあります。

### 120-150秒: Final Phase（固定フォーメーション）
- **実装**: `quadrant_json_generator.py`
- **動作**: 5行×4列のフォーメーションが象限間を移動（停止なし）
- **出力**: `quadrant_output/robot_XX.json`

## 用語の推奨

混乱を避けるため、以下の用語を使い分けることを推奨します：

| 用語 | 意味 | 使用例 |
|------|------|--------|
| **フォーメーション** | 固定相対位置で動く群 | "矩形フォーメーション"、"象限フォーメーション" |
| **群ロボット** | 自律的な群れ行動 | "群ロボット動作（50-120秒）"、"群シミュレーション" |
| **群** | 一般的な複数ロボットの集合 | "20台の群"、"群の中心" |

## 現状の問題点

1. **用語の混在**: 「群ロボット」が固定フォーメーションと自律的な群れ行動の両方に使われている
2. **ドキュメントの不整合**: `docs/rectangle_formation_spec.md`では「群全体が剛体として回転・移動」と記載されているが、これは「フォーメーション」と呼ぶべき
3. **実装の分離**: 固定フォーメーションと自律的な群れ行動は別々のスクリプトで実装されているが、用語が統一されていない

## 推奨される修正

1. **ドキュメントの用語統一**:
   - 固定フォーメーション → "フォーメーション" または "編隊"
   - 自律的な群れ行動 → "群ロボット" または "群れ行動"

2. **コードコメントの明確化**:
   - 各スクリプトの冒頭で、実装している制御方式を明記

3. **READMEの追加**:
   - プロジェクト全体の用語集を作成
