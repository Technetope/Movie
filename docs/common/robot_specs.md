# toioロボット仕様

## 速度制限

### キューブに何も載せない状態での最高速度
- **直進**: 350mm/sec
- **回転**: 1500deg/sec

### 載せ物がある状態での制限速度（本プロジェクト）
- **直進**: **200mm/sec**（制限）
- **回転**: **900deg/sec**（制限）

## toioの仕様
- サイズ: 7.2cm（奥行き）× 3.2cm（幅）× 4cm（車輪込みの高さ）
- 向き: toio cube 上向きが0度

## JSONでの速度指定

### 位置移動（直進）
- 最大速度: 200mm/sec
- 速度指定時はこの制限を考慮する

### 回転
- 最大速度: 900deg/sec
- 回転指定時はこの制限を考慮する

## 初期配置
- 30台のtoioが6個×5行（横に並べる個数のほうが多い）
- 等間隔で配置
- 間隔比率は回転運動時にぶつからないことが重要
- 向きは全部下向き（180°）
