# ロボットの音パターン（80-95秒）

## 概要
80-95秒の15秒間、ロボットがパターン化された音を鳴らす。

## 音ファイル
### reference/sound_base/ ディレクトリ内の音ファイル
- `aurora.wav`
- `birds.wav`
- `cicada.wav`
- `crystal.wav`
- `dolphin.wav`
- `drizzle.wav`
- `frog.wav`
- `geyser.wav`
- `insect.wav`
- `ocean.wav`
- `radio.wav`
- `reef.wav`

## 再生パターン

### 再生方法
- **順次再生**: 時間的に順番に音を再生する

### 最初（80秒付近）
- **任意の5台**が音を鳴らす
- **`reef.wav`** と **`dolphin.wav`** を流す
- 音の再生タイミングは**JSONの中で定義する**
- 座標が全て決まってから定義する

### その後（80秒後半〜95秒）
- **約20台**をいろんなタイミングで流し続ける
- 上記の音ファイルを組み合わせて使用
- 大量の音を様々に流す

## 提案するパターン（例）

### パターンA: 時間順次型
```
80.0秒: reef.wav
80.5秒: dolphin.wav
81.0秒: birds.wav, cicada.wav
81.5秒: drizzle.wav
82.0秒: ocean.wav
...
```

### パターンB: ロボット分散型
```
30台のロボットに音を割り当て：
- ロボット0-4: reef.wav
- ロボット5-9: dolphin.wav
- ロボット10-14: birds.wav
- ロボット15-19: cicada.wav
...
```

### パターンC: 重複型
```
複数のロボットが同時に異なる音を鳴らす：
80.0秒: ロボット0-5がreef.wav、ロボット6-11がdolphin.wav
80.5秒: ロボット12-17がbirds.wav、ロボット18-23がcicada.wav
...
```
