#### 30秒時点での位置の計算
**仮定A: 相対位置維持モデル**（推奨）
0-30秒の動作で、全ロボットが同じ方向・同じ距離を移動するため、**相対的な位置関係（グリッド構造）は維持される**と仮定。

この場合：
- 30秒時点での各ロボットの**相対的な位置関係**は初期配置とほぼ同じ
- フィールド中心からの初期半径（`r₀_i`）と初期角度（`θ₀_i`）は初期配置を基準に計算可能

#### フィールド中心からの初期パラメータ計算
各ロボットID `i`について（30秒時点）：
```
center_x = 491.5
center_y = 466.5

dx_i = x_i - center_x
dy_i = y_i - center_y

r₀_i = √(dx_i² + dy_i²)
θ₀_i = atan2(dy_i, dx_i) × 180 / π
```

**注意**: `atan2(dy, dx)`はX軸正方向から反時計回りの角度（-180°～180°）
- 0°以上にする場合: `θ₀_i = (θ₀_i + 360) % 360`（0°～360°）

## 螺旋運動の設計アプローチ

### アプローチA: 角速度一定モデル（確定・推奨）
全ロボットが**同じ角速度**で回転し、外側のロボットが速く移動する方式。**放射状拡散モデル**。

#### 回転運動の基本方針
- **全ロボットが同じ角速度（35deg/sec）で回転**
- **各ロボットの初期角度（θ₀）を維持しながら回転**
- **半径のみが時間経過とともに拡大**
- **連動感を保ちやすく、螺旋状のパターンが自然に形成される**

#### 速度計算式
```
v(r) = r × ω
```
- `v(r)`: 距離`r`での線速度（mm/sec）
- `r`: 中心からの距離（mm）
- `ω`: 角速度（rad/sec）**一定** = 35deg/sec = 0.611 rad/sec

#### 角速度の設定（確定）
- **角速度**: **35deg/sec**（0.611 rad/sec）**確定**
  - 安全な範囲（100deg/sec以下）
  - 連動感を保つため、全ロボットが同じ角速度
  - 10.3秒で1回転（360° ÷ 35deg/sec）

#### 回転方向
- **推奨**: **反時計回り**（toioの角度定義に合わせる）
- 全ロボットが統一された回転方向で回転

#### 半径の拡大（時間経過）
初期配置から徐々に螺旋状に広がっていく：
- **30秒**: 初期半径`r₀`（初期配置の中心からの距離）
- **50秒**: 最終半径`r_max`（十分に散らばった状態）

#### 半径の時間変化（宇宙軌道のメタファー）
**線形だが加速的な拡大**：最初はゆっくり、だんだん早く大規模になっていく

第一宇宙速度 → 第二宇宙速度のメタファー：
- **30秒付近（第一宇宙速度）**: 小さな軌道、ゆっくりとした拡大
- **45-50秒（第二宇宙速度）**: 軌道から脱出、大きく広がる

#### 加速的な線形拡大モデル
半径拡大の加速度を考慮：

```
r(t) = r₀ + a × (t - 30)² / 2
dr/dt = a × (t - 30)
```

ここで：
- `t`: 時間（30秒 ≤ t ≤ 50秒）
- `r₀`: 初期半径（各ロボットの初期位置から中心までの距離）
- `a`: 半径拡大の加速度（mm/sec²）**一定**
- `r_max`: 最終半径（50秒時点、`r(50) = r₀ + a × 200`から算出）

**30秒時点**: `dr/dt = 0`（最初はゆっくり）  
**50秒時点**: `dr/dt = a × 20`（最後は早く広がる）

- `t`: 時間（30秒 ≤ t ≤ 50秒）

```

```

## 最終半径（r_max）の決定方法（確定）

### 最終半径の戦略: 初期位置に応じた拡大率モデル（確定）

全ロボットが同じ`r_max`ではなく、**初期半径に応じて異なる拡大率を適用**することで、自然な分散を実現。

#### 基本方針
- **中央のロボット**: 初期半径が小さいため、より大きく拡大（拡大率が大きい）
- **外側のロボット**: 初期半径が大きいため、それほど大きく拡大しない（拡大率が小さい）
- **結果**: 全体的に均一に散らばり、分散度75%以上を達成

#### 最終半径の計算式（確定）
```
r_max_i = r_base + (r₀_i - r_min) × k
```

ここで：
- `r_base`: 最小最終半径（mm）**300mm**
- `r_min`: 最小初期半径（mm）**82mm**（推定）
- `r_max_i`: ロボットiの最終半径（mm）
- `r₀_i`: ロボットiの初期半径（mm）
- `k`: 拡大係数 **0.3**（初期半径差に対する拡大の敏感度）

#### パラメータ設定（確定）
- **r_base**: **300mm**（すべてのロボットの最小最終半径）
- **k**: **0.3**（初期半径1mmの差が、最終半径0.3mmの差に反映）
- **r_max_max**: **380mm**（速度制限のため、最大最終半径を制限）
- **r_maxの計算**: `r_max_i = min(300 + (r₀_i - 82) × 0.3, 380)`
- **r_maxの範囲**: 約**300mm ～ 380mm**
  - 最小初期半径（82mm）の場合: `r_max = 300 + (82 - 82) × 0.3 = 300mm`
  - 最大初期半径（559mm）の場合: `r_max = min(300 + (559 - 82) × 0.3, 380) = min(443, 380) = 380mm`

#### 拡大率の計算
```
拡大率_i = (r_max_i - r₀_i) / r₀_i × 100%
```

**例**:
- 初期半径82mmの場合: 拡大率 = (300 - 82) / 82 × 100% ≈ 266%（大きく拡大）
- 初期半径300mmの場合: 拡大率 = (365 - 300) / 300 × 100% ≈ 22%（小さく拡大）
- 初期半径559mmの場合: 拡大率 = (443 - 559) / 559 × 100% ≈ -21%（むしろ縮小、フィールド内に収めるため）

**注意**: 外側のロボットは既にフィールド端に近いため、拡大を抑えフィールド内に収める。

#### 分散度の定義
50秒時点での分散度 = (実際に使用されているフィールド範囲) / (フィールド全体の範囲) × 100%

#### 初期パラメータ計算（数列的計算）

2. 回転角度: `theta_i(t) = theta0_i + 35 × (t - 30)`
